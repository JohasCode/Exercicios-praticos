# Validação de campo de e-mail
## Sobre o projeto
O objetivo era construir uma função simples para **validação de campo de e-mail** de um determinado formulário feito em HTML utilizando a plataforma [Playcode](https://playcode.io/).

## Aprendizados e desafios
Achei a plataforma Playcode bastante prática e eficiente, possuindo recursos muito úteis para o
desenvolvimento web como a pré-visualização da página web em tempo real. Porém, ela é
bastante extrema na exigência de migração para o plano pago, dizendo ter um limite de apenas
8 linhas de código e bloqueando você constantemente com um pop-up de assinatura com
cooldown.

Tirando isso, é uma plataforma online de criação de código que, sem restrições, valeria a pena.
Esta atividade me permitiu exercitar a programação HTML, CSS e Javascript, a criação de
formulários de validação, o uso das tags de conversão da linguagem (<style> e <script>) e a resolução de
problemas.

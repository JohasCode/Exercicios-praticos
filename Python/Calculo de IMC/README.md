# Calculo de IMC
## Sobre o projeto
Um sistema em Python para **calcular o IMC** com valores que o usuário definir. O IMC é calculado por meio da divisão do peso do indivíduo pela altura, em metros, ao quadrado.

<img width="323" height="128" alt="image" src="https://github.com/user-attachments/assets/4567d51f-73b3-4685-8010-cc13a17b17ac" />

Dessa forma, entendemos que a fórmula para descobrir o IMC é “peso/altura²” ou “peso/(altura x altura)”, e não é só isso, o IMC possui uma classificação de acordo ao resultado, como pode ser visto na tabela abaixo.

<img width="679" height="238" alt="image" src="https://github.com/user-attachments/assets/be5b9b32-2ca1-42a7-ad6c-9c87bb20bd11" />

## Funcionalidade
Ele permite que o usuário defina o valor referente ao Peso e a Altura desejada, executando o cálculo dos valores definidos e exibindo o resultado e sua classificação.
